# 🎰 Ludopatics

Bienvenidos a **Ludopatics**, una aplicación de ruleta desarrollada en Android Studio que pone a prueba la suerte y la intuición del usuario en partidas breves, dinámicas y llenas de estrategia.

## 🧠 ¿Qué es Ludopatics?

Es un juego de ruleta multilingüe con animaciones reales, donde el objetivo es terminar las 10 rondas con más dinero del que tenías al empezar. Puedes apostar a par/impar, color o número, y decidir si ir a lo seguro o arriesgar más. Las partidas perdidas suman al bote común... ¡que se lleva el ganador!

## 🛠️ Tecnologías usadas

- Android Studio
- Java
- XML (para las interfaces)
- Multilenguaje: español, inglés, francés y japonés

## 🎮 Características principales

- 🎡 Ruleta animada desde cero
- 👥 Modo multijugador local
- 🎯 Apuestas múltiples en cada ronda
- 💰 Sistema de bote acumulativo
- 🌐 Disponible en cuatro idiomas
